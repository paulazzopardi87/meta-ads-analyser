# Meta Ads Manager — column preset setup

Save this column layout once. After that, exporting takes 15 seconds.

## Columns to add (in this order)

Search for each one in the "Customise columns" panel:

| Column name to search for | What it tells you |
|---|---|
| Ad name | Which creative |
| Ad set name | Which audience / campaign structure |
| Impressions | How many times shown |
| Reach | Unique people reached |
| Amount spent | Your spend this window |
| Link clicks | Clicks through to your site (use link version, not all clicks) |
| CTR (link click-through rate) | % of impressions that clicked through — creative quality signal |
| CPC (cost per link click) | Cost per site visit — use link version |
| Add to cart | People who added to cart |
| Purchases | Confirmed purchases (Meta-attributed) |
| Purchase ROAS | Return on ad spend |
| Cost per purchase | Your CPA |

## How to save as a preset

1. After adding all columns, click **Save** at the bottom of the column panel
2. Name it: `My Ads OS` (or anything you'll recognise)
3. From now on: Columns → select preset → done

## Important: link vs all clicks

When adding CTR and CPC, make sure you select the **link** versions:
- ✅ CTR (link click-through rate)
- ✅ CPC (cost per link click)
- ❌ Not "CTR (all)" — that includes link clicks, post reactions, and profile visits

The link versions measure people who actually went to your site. That's what matters.

## Attribution window

The analyser assumes **7-day click / 1-day view** attribution — Meta's standard setting.

If you've changed your attribution window, note it in the prompt so the AI can account for it.

## Date range

- **Weekly analysis:** Last 7 days
- **New creative evaluation:** Lifetime (gives you the full picture since the ad launched, even if it's only been running 3 days)
