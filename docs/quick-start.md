# Quick start: your first verdict in 10 minutes

## 1. Know your numbers (once)

| You'll need | Example |
|---|---|
| Average order value, as the customer pays it | £30.00 |
| VAT included? Rate? | Yes, 20% |
| COGS per order | £6.00 |
| Payment fees per order | £0.80 |
| Fulfilment per order (minus shipping the customer pays) | £3.20 |
| Typical daily budget | £90/day |

The analyser turns these into your **break-even CPA**, **target CPA** and **break-even ROAS**. Every verdict is measured against them.

## 2. Export from Meta (once to set up, then 15 s/week)

1. [Ads Manager](https://adsmanager.facebook.com) → **Ads** tab
2. Date range: **Last 7 days** (it excludes today, which you want)
3. Columns → set up the preset in [column-preset.md](column-preset.md) → save it
4. Reports → **Export table data** → CSV

## 3. Run it

**Claude with the skill installed:** new chat → attach CSV → *"analyse my ads"* → answer the economics questions on first run.

**Any AI chat:** paste [magic-prompt.md](magic-prompt.md) with section A filled in, attach the CSV, send.

## 4. Act on it

- Do the **"Do this now"** actions (max 3) within 24 h
- **KILL** → turn off. **SCALE** → +20–30% budget, then don't touch for 3–4 days
- **FIX PAGE** → fix the page, not the ad
- **WATCH / NO DECISION YET** → do nothing; the report tells you when to look again

## Weekly routine

| When | What |
|---|---|
| Monday | Export last 7 days → run analyser → act on "Do this now" |
| Mid-week (optional) | Re-check new creative tests only: creative kills can happen once an ad has 2,000 impressions |
| Never | Change budgets daily, judge an ad in its first 72 h, or call CPA on fewer than 10 sales |
